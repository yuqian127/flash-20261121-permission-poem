## What it does

`main.ts` (Node 22) writes one short poem about agency — the power to ask and to be given — to `/output/entry.txt`. The poem is 231 characters, inside the bounty's 1–280 character limit (counted as Unicode code points). No network, no input, fully deterministic.

## The poem

> A licence is a key, not a lock —
> a small door, left open, in a wall.
> Take this line, this light, this clock,
> and carry it somewhere it can grow tall.
>
> Borrow boldly, build, and give it back
> a little brighter than you found it here.
